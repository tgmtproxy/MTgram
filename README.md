# MTgram

ещё один форк телеграма. но этот — наш.

Качаешь, пользуешься. Мы делаем чтобы Telegram выглядел лучше и работал там, где оригинал блокируется.

---

## Что это такое

Обычный Telegram, только лучше. Без рекламы, без лишнего, с нормальным интерфейсом.

Основная идея простая: берём официальный Telegram, чиним то что раздражает, добавляем то чего не хватает.

---

## Что мы сделали

**Внешний вид**
- Нормальное боковое меню вместо нижних вкладок (как раньше было)
- Material You — тема подстраивается под цвет твоего телефона
- Можно менять шрифт на свой
- Скрыть свой номер из интерфейса
- Дату регистрации видно в профиле

**Удобство**
- Двойное нажатие на вкладку аккаунта — переключает на следующий
- Секунды в метках времени
- Настройка скорости анимаций (вплоть до мгновенной)
- Экспорт/импорт настроек

**Приватность**
- Paranoia Mode — прячет выбранные чаты отовсюду: из уведомлений, из поиска, из списка
- PIN на аккаунт + паник-код чтобы сбросить всё к стандартному виду
- Убраны Google Play Integrity и reCAPTCHA
- Ссылки очищаются от трекинг-параметров (utm, fbclid и т.п.)

**Сеть**
- Улучшенный TLS fingerprint — прокси работает там, где оригинальный Telegram блокируется
- Быстрая загрузка файлов

## Сборка

Нужен Android Studio и файл `API_KEYS` в корне:
```
APP_ID = твой_id
APP_HASH = твой_hash
```

API ключи: https://core.telegram.org/api/obtaining_api_id
